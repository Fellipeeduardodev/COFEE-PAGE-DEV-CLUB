# COFEE PAGE - DEV CLUB ☕

Projeto de uma página web simples com temática de café, desenvolvido como parte dos estudos no **Dev Club**.  
O objetivo é praticar HTML e CSS, criando um layout visualmente agradável e organizado.

---

## 📌 Sobre o Projeto

Esta é uma **página estática** focada em layout e estrutura, ideal para estudos e aprimoramento em desenvolvimento front-end.  
O projeto ainda está em evolução e novas melhorias serão adicionadas.

> 🚧 **Em breve o projeto contará com versão responsiva para dispositivos móveis e tablets.**
